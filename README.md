# RobotArmSmooth — ควบคุมแขน 4 ข้อแบบนุ่ม

แขน SCS15 × 4 (ฐาน 4, ไหล่ 9, ศอก 7, คอ 2) ผ่าน Waveshare Bus Servo Adapter (A) จัมเปอร์ B → **COM11** · ไฟ servo **7.4 V เท่านั้น**
ต่อยอดจาก `D:\PIM\RobotControl\v2` · design: `docs/design.md`

```
[■ หยุด] [เชื่อมต่อแขน]  แขนจริง  ไฟ 7.8 V
ฐาน  ═══●═══          ┌ ภาพ 3D (ลากเมาส์หมุนได้) ┐
ไหล่ ═══●═══          │ ทึบ = ท่าที่สั่ง           │
ศอก  ═══●═══          │ ประ = มุมจริงจาก servo    │
คอ   ═══●═══          └───────────────────────┘
ไปจุด X[ ] Y[ ] Z[ ] [ไปจุดนี้]   ความเร็ว ══●══ °/s
```

- **เปิด:** ดับเบิลคลิก `RobotArm.bat` → เปิดมาเป็นโหมดจำลอง → กด "เชื่อมต่อแขน" (แขนค้างที่เดิม ไม่ขยับเอง)
- **Slider:** ลากแล้วแขนไล่ตามแบบนุ่ม · **ไปจุด:** ใส่ X Y Z (mm) → ปลายแขนวิ่งเส้นตรง (φ เลือกให้อัตโนมัติ; ใกล้ท่าเหยียดสุดจะหมุนข้อต่อแทน)
- **หยุด:** ปุ่มแดงซ้ายบน — แขนค้างที่ตำแหน่งจริงทันที · ไฟ < 6 V / servo ไม่ตอบ → หยุดเอง · หลังถึงเป้าชดเชยแขนยวบให้อัตโนมัติ
- **คาลิเบรต:** `Calibrate.bat` → บันทึกลง `src/config.py` (ค่าอยู่ที่เดียว) แล้วเปิด RobotArm ใหม่
- jog / แท็บ / ปุ่ม torque ยังอยู่ใน `motion.py` (`jog_joint`, `jog_xyz`) แต่ตัดออกจากหน้าต่างเพื่อให้ง่าย

ติดตั้ง: `py -3.11 -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements.txt`
test: `cd src && ..\.venv\Scripts\python.exe -m pytest -q`
