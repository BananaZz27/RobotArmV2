**Mover** (หน่วยองศา, วินาที; setpoint `q` = ท่าที่กำลังสั่ง):
- `goto_q(q_goal)` — ทาง joint: ทุกข้อใช้โปรไฟล์ min-jerk `s(τ) = 10τ³ − 15τ⁴ + 6τ⁵` ร่วมกัน → ถึงพร้อมกัน, T = 1.875·Δmax / v_max
- `goto_xyz(x, y, z, φ)` — เส้นตรงในอวกาศ: IK ทุก ~1 mm ตามเส้น, เวลาตามโปรไฟล์ min-jerk โดย T ยาวพอให้ทั้งปลายแขน ≤ v_cart และทุกข้อ ≤ v_max · จุดไหน IK ไม่ได้ → ใช้ทาง joint ไปที่ IK ของปลายทาง (ปลายทาง IK ไม่ได้ = ปฏิเสธ)
- `jog_joint(i, ±1)` / `jog_xyz(axis, ±1)` / `release()` — ความเร็วเร่งขึ้นด้วย a_max, ปล่อยแล้วผ่อนจนหยุด · jog xyz: ปลายแขน += v·dt แล้ว IK (φ คงที่) — IK ไม่ได้ / ชน limit → หยุดแกนนั้น + บอกเหตุผล
- `follow(q_goal)` — slider: ไล่ตามด้วย v ≤ v_max, ผ่อนก่อนถึง (v ≤ √(2·a·|e|))
- `stop()` — v = 0 ทันที ทิ้งเป้า · `reset(q)` — ตั้ง setpoint = มุมจริง
- ทุกค่าบีบใน `Q_MIN..Q_MAX` · แขน 4 ข้อ (J5 หัวเอาออกจากโปรแกรมแล้ว 2026-11-20)
- ค่าเริ่มต้น `V_JOINT = 10 °/s`, `A_JOINT = 30 °/s²`, `V_CART = 20 mm/s`, ปรับใน GUI ได้ ≤ 30 °/s

**ส่งให้ servo:** ทุก 40 ms ส่งท่า setpoint พร้อมเวลา 60 ms (servo เกลี่ยระหว่างจุด) — DirectLink โหมดป้อนท่าไม่บังคับ 300 ms แต่ **ปฏิเสธคำสั่งที่ข้อไหนกระโดด > 3° ใน < 300 ms** (กันบั๊ก)

**ความปลอดภัย:** ไฟ < 6 V / ออฟไลน์ → `stop()` + ค้างที่มุมจริง + ข้อความ · ปุ่มหยุด = `stop()` + `link.stop()` (goal = ตำแหน่งจริง) + `reset(มุมจริง)` · เปิดโปรแกรม/ต่อแขน = ค้างที่เดิม ไม่ขยับเอง

**ชดเชย (เปิด-ปิดได้, ค่าเริ่มเปิด):** หลัง `goto_*` จบ รอ 0.4 s → ข้อที่ |error| > 0.5° และ < 5° → `goto_q(setpoint + 0.8·error)` แบบนุ่ม ≤ 3 รอบ, ชดเชยรวม ≤ ±5°

**หน้าต่าง:** แถบบน (เชื่อมต่อ/จำลอง, ไฟ, ปลด/ล็อก torque, ปุ่มหยุดใหญ่) · แท็บ Jog / เป้า / Slider · ความเร็ว · ตัวเลขมุมจริง+XYZ · ภาพจำลอง 2 มุม (sim_view)
